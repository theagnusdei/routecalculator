## Texto extraído

An AMD engineering sample has made an appearance in a listing on OpenBenchmarking. According to a report by TechPowerUp, the chip could potentially be a part of AMD’s upcoming Gainsborough family and a possible candidate for the next-generation Steam Deck handheld console. As per the OpenBenchmarking listing, the chip comes with a six-core, 12-thread processor paired with 24GB of high-speed LPDDR5 memory.
The engineering sample with part number 100-000001930-12_Y was tested on an AMD GBR-FF6-SKT validation board, with the CPU running at clock speeds of 2.4 GHz. The system also features four 6GB SK Hynix memory packages, resulting in 24GB of LPDDR5 memory running at 9,600 MT/s. That’s a big jump when compared to the current Steam Deck, which comes with 16GB of LPDDR5 memory running at 6,400 MT/s, alongside a four-core, eight-thread AMD Zen 2 processor.
The benchmark listing also provides some clues about the processor’s underlying architecture. As per Notebookcheck, the sample’s CPU microcode revision corresponds to AMD’s Family 1Ah, model DCh. Linux kernel changes indicate that this model falls within the range reserved for newer Zen 6 processors, suggesting that Gainsborough could use AMD’s next-generation CPU architecture. However, there is no clarity or any confirmation whether it will use standard Zen 6 cores or the denser Zen 6C variant.
The integrated GPU is listed with a clock speed of 2,400 MHz, although its architecture and compute unit count remain unknown. The sample was tested using the GpuTest benchmark suite on Ubuntu 24.04 at 1024 x 768 resolution, resulting in scores of 3,871 in GiMark, 3,508 in FurMark, and 9,319 in TessMark. While the FurMark score is comparable to the original Stam Deck, we can’t really come to any conclusions at this point, as the tests were conducted on an engineering platform using development software rather than a finished handheld. For now, the results do not establish how the chip would perform in games, as power limits, cooling, driver maturity, and the final GPU configuration all contribute to the performance in a compact gaming device.
If these specifications carry over to a future Steam Deck, the additional CPU cores along with the larger and faster memory would provide a meaningful hardware upgrade. That being said, neither AMD nor Valve have confirmed a connection between the Gainsborough family and a future Steam Deck. Thus, it is best to take this with a grain of salt and wait until there is more concrete information in the future.
