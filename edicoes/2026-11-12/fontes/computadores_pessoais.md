## Texto extraído

Windows allows you to create multiple desktops, so that users can quickly switch between a work environment, a personal one, and a desktop optimized for gaming. This often leads to overlap: a word processor, for example, is normally needed for both work and personal correspondence.
If the program is running in full-screen mode, it’s often hard to tell which desktop you’re currently on. The simplest method is to assign a different background to each desktop. However, this must be a background image; Windows applies solid colors uniformly across all desktops.
Foundry
And, of course, the wallpaper trick only works if you’re not using the current application in full-screen mode. The open-source program Windows Virtual Desktop Helper offers a better solution. Once installed, you’ll find the tool in the Start menu under ‘Recommended.’ As soon as you’ve launched it by double-clicking, it appears in the corner of the taskbar with three new entries.
A number or an initial letter indicates which desktop you’re currently on. Right-click and select ‘Settings’ from the context menu to access the program’s settings. You can quickly switch between your desktops using the arrow keys.
