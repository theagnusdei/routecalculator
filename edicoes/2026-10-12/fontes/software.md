Fotos apagadas deixam rastros perigosos no Windows; veja como eliminar tudo
Por André Lourenti Magalhães • Editado por Jones Oliveira |
Mesmo após apagar uma foto, o Windows ainda pode armazenar registros do arquivo no sistema. Isso ocorre com a criação de dados temporários, mas há um caminho para removê-los rapidamente no PC.
Por padrão, o Explorador de Arquivos cria miniaturas para a pré-visualização de imagens e armazena os arquivos em cache. A medida agiliza o carregamento dos resultados ao abrir a mesma pasta novamente, mas também abre uma brecha para encontrar rastros de conteúdos que já foram apagados.
Vale destacar que nem toda imagem apagada ganha uma miniatura própria, mas existe um caminho para evitar a dor de cabeça e possíveis problemas com privacidade.
Onde ficam os rastros de imagens apagadas?
Os arquivos temporários com as miniaturas ficam armazenados no caminho %LocalAppData%\Microsoft\Windows\Explorer e recebem nomes como “thumbcache_2560” (a numeração varia de acordo com a resolução da imagem).
O formato é o .db, usado para bases de dados, e não é possível acessar as imagens diretamente pelo Explorador de Arquivos — é necessário usar um software para extrair as informações.
Normalmente, as miniaturas são criadas ao abrir os arquivos pelo Explorador do Windows. Caso você delete uma imagem sem acessá-la pelo app, é possível que o sistema não gere um arquivo.
Como apagar os dados temporários no PC
Os arquivos são temporários, mas existe uma forma nativa para remover as miniaturas com a ferramenta Limpeza de Disco. Confira:
- Procure por “Limpeza de Disco” na busca e abra o app;
- Selecione a opção “Miniaturas”;
- Conclua a limpeza.
