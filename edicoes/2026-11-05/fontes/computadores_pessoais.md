## Texto extraído

In summary:
- PCWorld reports that Google’s Chrome 157 update addresses 213 security vulnerabilities, including seven critical flaws and 77 high-risk issues, with external researchers rewarded $31,000 for discoveries.
- Common bugs involved use-after-free errors and V8 engine data leaks, making this update essential for user protection.
- Chrome users should update immediately via the Help or Settings menu to stay secure against these significant risks.
Google just released Chrome 157.0.8103.38/39 for Windows and macOS and 157.0.8103.38 for Linux, fixing over 200 security vulnerabilities, some of which are critical. According to Google, none of the patched vulnerabilities have been exploited in the wild yet.
Chrome 158 is due to be released in two weeks.
What’s new in Chrome 157?
In Chrome’s “What’s New” page that shows after updating, Google announces a new feature for sending open browser tabs to all (or select) devices. To use this feature, you’ll need to be signed in to Chrome with the same account on all sending and receiving devices (phone, tablet, laptop).
When sending from your PC, you don’t need to use the unnecessarily fiddly method of three-dot menu → Stream, save, and share → Send to my device. Instead, it’s quicker if you right-click on the relevant tab and select Send to my device from the context menu.
When sending from your Android device, open the tab you want to send, then press and hold the address bar and select Send to my device. This has worked this way since Chrome 77 (2019), so it’s not really news.
Security flaws fixed in Chrome 157
In the Chrome Releases blog post, Srinivas Sista lists 213 security vulnerabilities that were fixed. Google discovered 130 of them internally, while the rest were identified and reported by external security researchers. Google has so far awarded those researchers a total of $31,000 in bounties.
Seven vulnerabilities have been classified as critical, with four of them being use-after-free (UAF) vulnerabilities in various components. A further 77 vulnerabilities are classified as high risk. Of the remaining vulnerabilities, 75 are considered medium risk and 54 low risk. The most common types of vulnerabilities are use-after-free vulnerabilities (45), data leaks (13), and type mix-ups (13). The latter occur primarily in the V8 JavaScript engine.
Chrome usually updates automatically when a new version is available. You can manually check for updates via the menu in Help → About Google Chrome (alternatively, in Settings → About Google Chrome).
